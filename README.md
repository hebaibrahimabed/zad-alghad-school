# Zad Alghad School

نظام إدارة مدرسة زد الغد - نظام متكامل لإدارة شؤون الطلاب والتسجيل والإحصائيات

## نظرة عامة

مشروع Zad Alghad School هو نظام إدارة مدرسي مبني باستخدام Laravel 10 وواجهة AdminLTE الحديثة، ويوفر بيئة متكاملة لإدارة بيانات الطلاب والتسجيل المدرسي والإحصائيات والتقارير، مع دعم كامل للغة العربية واتجاه RTL.

يهدف النظام إلى تسهيل العمليات الإدارية داخل المدارس وتحسين إدارة بيانات الطلبة من خلال واجهة سهلة الاستخدام وآمنة ومتجاوبة مع جميع الأجهزة.

## ميزة تحديد الصف حسب العمر تلقائيًا

يقوم النظام بتحديد الصف الدراسي للطالب تلقائيًا اعتمادًا على:

* تاريخ ميلاد الطالب
* تاريخ اعتماد القبول المدرسي
* العمر المطلوب لكل صف

يتم احتساب العمر بشكل ديناميكي وفق السنة الدراسية الحالية دون الحاجة لتعديل الكود سنويًا.

### أمثلة

| العمر عند تاريخ الاعتماد | الصف   |
| ------------------------ | ------ |
| 4 سنوات                  | بستان  |
| 5 سنوات                  | تمهيدي |
| 6 سنوات                  | الأول  |
| 7 سنوات                  | الثاني |

## التثبيت

### 1. استنساخ المشروع

```bash
git clone <repository-url>
cd zadAlghadSchool
```

### 2. تثبيت الاعتماديات

```bash
composer install
npm install
```

### 3. إعداد ملف البيئة

```bash
cp .env.example .env
php artisan key:generate
```
